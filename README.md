# Presupuesto General de la Nación (PGN) - Datos

Repositorio con los datos y análisis de presupuesto (PGN 2025).

## Contenido

- `data/*.zip`: Archivos comprimidos de gastos del PGN mensuales (enero a diciembre 2025).
- `data/relevantes_bioquimica_2025-12.csv`: Datos filtrados correspondientes a bioquímica / laboratorio.
- `data/salarios_laboratorio_2025-12.csv`: Datos de salarios de laboratorio.

> **Nota:** Los archivos descomprimidos (`data/extracted/`) no se incluyen en el repositorio debido a que superan el límite de tamaño de archivo de 100 MB de GitHub. Se pueden descomprimir localmente a partir de los `.zip` de la carpeta `data/`.
